A single funny line for the [One Line, One Laugh](https://make.fun/c/u-deysumbrella-one-line-one-laugh-e0cdcda9) bounty on make.fun — a $2 winner-takes-all competition for one line, 1–140 characters.

## The entry

> My password is so strong that even I can't log in — my accounts are now protected from me, personally.

(102 characters.)

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt` when run:

```sh
python3 main.py
```

The output file is written with mode `0644` so the grader can read it.
